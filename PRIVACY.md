# Privacy Policy — Opening Fenix Chess

**Last updated:** 2026-11-26

Opening Fenix Chess is an open-source desktop chess opening trainer. Your privacy is respected by design:

## 1. Data Collection
Opening Fenix Chess does **not** collect, track, sell, or transmit any personal data, analytics, or telemetry to the developer or any third party.

## 2. Local Data Storage
All repertoires, training progress, profiles, and settings are stored **locally on your device** (in your user application data folder or a folder you choose).

## 3. Optional Online Services
Opening Fenix Chess only connects to the internet when you explicitly use optional features:
- **Lichess API (Optional):** If you choose to enter a Lichess API token or query Lichess opening explorer / cloud evaluation databases, requests are sent directly from your device to `lichess.org` under [Lichess's Privacy Policy](https://lichess.org/privacy). Your optional API token is stored only in your local configuration file.
- **Chess Engine Downloads (Optional):** If you choose to download an open-source chess engine (such as Stockfish) from within the app, it is downloaded directly from its official release source.

## 4. Contact
If you have questions about this privacy policy, please open an issue on the project repository:
https://github.com/Takais-Chess/Opening-Fenix/issues
